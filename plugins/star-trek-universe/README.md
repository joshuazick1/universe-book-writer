# Star Trek Universe Plugin

Official Star Trek Universe plugin for Universe Book Writer with LCARS theme and Starfleet protocols.

## Features

- **Sub-Universes**: Prime Timeline, Kelvin Timeline, Mirror Universe, Custom Timeline
- **LCARS Theme**: Authentic Star Trek interface styling
- **Starfleet Protocols**: Built-in validation for ranks, species, and technology
- **AI Integration**: Era-specific writing prompts and character development
- **Visual Components**: LCARS bars, panels, and interactive elements

## Sub-Universes

### Prime Timeline
- **Description**: The original Star Trek timeline
- **Supported Eras**: TOS, TNG, DS9, VOY, ENT, DSC, PIC
- **Canon Level**: Strict adherence to established canon

### Kelvin Timeline  
- **Description**: Alternative timeline from 2009 films
- **Supported Eras**: Kelvin timeline events
- **Canon Level**: Flexible interpretation

### Mirror Universe
- **Description**: Dark parallel universe with Terran Empire
- **Supported Eras**: TOS, TNG, DS9, ENT, DSC
- **Canon Level**: Flexible with established mirror universe rules

### Custom Timeline
- **Description**: User-defined timeline with custom rules
- **Supported Eras**: All eras available
- **Canon Level**: User-defined

## Usage

The plugin automatically provides:
- Species validation (Human, Vulcan, Klingon, Romulan, etc.)
- Starfleet rank structure
- Technology consistency checks
- Era-appropriate language and concepts
- LCARS visual theming
