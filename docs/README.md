# VerseForge Documentation

Welcome to the VerseForge documentation directory. This folder contains all project planning, technical, and process documentation for the Multi-Universe Book Series Writing Assistant.

## Main Documentation

- **[CONSOLIDATED_PROJECT_DOCUMENTATION.md](./CONSOLIDATED_PROJECT_DOCUMENTATION.md)**  
  The single source of truth for project phases, architecture, and guidelines.

- **Phase Checklists:**  
  Located in `checklists/`, these provide detailed deliverables and timelines for each project phase.

- **[DECISION_LOG.md](./DECISION_LOG.md)**  
  Records all major architectural and process decisions.

- **[PROGRESS.md](./PROGRESS.md)**  
  Tracks project progress and completed milestones.

- **[PHASE_ORDER_ANALYSIS.md](./PHASE_ORDER_ANALYSIS.md)**  
  Documents the rationale for the current phase order.

## Archive Policy

All legacy or superseded documentation is moved to the `archive/` folder for historical reference.  
Please consult the main documentation before referencing archived files.

## Contributing

To propose changes or additions to the documentation, please update the relevant file and submit a pull request.  
For major changes, update the `DECISION_LOG.md` and cross-reference in the main documentation.
