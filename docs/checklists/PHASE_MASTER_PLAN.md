## 🎯 **VerseForge Vision**

A comprehensive, **RAG-first**, AI-powered platform for writing, world-building, and collaborative management of book series and fictional universes. Features an **Obsidian-style knowledge graph** with timeline-aware context, **plugin-native** universe-specific features, multimodal AI assistance (Ollama), and real-time collaboration. Built from the ground up with **clean slate architecture** optimizing RAG content storage, encryption-first privacy, and plugin-aware knowledge management.

## 🏗️ **VerseForge Core Module Architecture**

### **Workspace Module** 🖥️
- **Features**: Modular, dockable, drag-and-drop panels (editing, AI, timeline, references, code explorer, plugin views)
- **Advanced**: Save/load custom workspace layouts, focus/distraction-free writing mode, version history and comparison
- **UI Delivery**: Layout framework and panel system by A.3, drag-and-drop by A.4

### **Editor Module** ✏️
- **Features**: Rich text editing with formatting ribbon, inline AI actions (rewrite, expand, check consistency)
- **Advanced**: Code editing with syntax highlighting, linting, code completion; word count/progress tracking; plugin support for custom editing tools
- **UI Delivery**: Basic rich text editor by A.3, formatting ribbon and AI integration points by A.4

### **AI Chat Box Module** 🤖 [CORE INNOVATION]
**Main multimodal conversational interface with extensible rendering pipeline**

- **In-Character Mode**: Select character(s) and timeline spot; responses reflect context, knowledge, mood, and relationships at that moment
- **Out-of-Character Mode**: User-defined AI personality/tone for brainstorming, meta-discussion, or general chat
- **Mode Toggle**: Switch anytime between in-character and out-of-character modes
- **Multimodal Output**: Supports text, code, media, data visualizations, and interactive widgets
- **Embedded iframes**: AI or user can request iframe panels for tutorials, demos, external resources (with security sandboxing)
- **AI-Generated UI Elements**: AI can define and render custom UI components (forms, tables, charts, tooltips, progress bars) in response to queries
- **Window Separation**: Chat box responses and AI-generated UI/iframes are visually/logically separate from editor suggestions
- **Independent Context**: Each chat/query defines its own context (universe, chapter, code file, persona, plugin, etc.)
- **Personality Config**: UI for defining/tweaking AI personality in out-of-character mode
- **Insert to Editor**: Manual option to copy/insert AI responses; no automatic editing
- **Plugin Extensions**: Plugin hooks for new UI element types and iframe integrations

**UI Extensibility Requirements**:
- Extensible rendering pipeline allowing AI/plugins to inject:
  - iframes (with security controls)
  - custom React/Vue components or specification-based widgets
  - dynamic forms and data visualizations
- All injected/AI-generated UI must be sandboxed and meet accessibility requirements

**Schema**: `ai_chat_message` with types: ["text", "code", "media", "iframe", "custom_ui"]

**UI Delivery**: Basic chat interface by A.3, extensibility hooks and iframe support by A.4

### **RAG (Retrieval-Augmented Generation) System Module** 🧠 **[CORE ARCHITECTURE]**
**Obsidian-style knowledge graph serving as the primary content store and semantic engine**

- **Architecture**: RAG-first design with database as high-performance index layer
- **Storage Strategy**: All narrative content in RAG, structured metadata in database for fast queries
- **Node Types**: Characters, locations, plot points, events, lore, books, chapters, scenes, dialogue + **coding examples, validation rules, templates** + plugin-defined types
- **Relationships**: Semantic connections, temporal relationships, character interactions, plot dependencies + **code dependencies, rule hierarchies, template inheritance**
- **Context Layering**: Multi-layer context system (Layer 0: focal point, Layer 1-3+: distance-based summarization)
- **Timeline Integration**: Temporal relationship mapping with character/world event intersections
- **Plugin Native**: Universe-specific node types (Star Trek: Starships, Star Wars: Force connections)
- **Encryption**: Field-level encryption with content-aware privacy classifications
- **Performance**: Database pre-filtering + RAG semantic search for optimal query performance
- **AI Integration**: Smart context assembly, relevance scoring, dynamic context windows

**UI Delivery**: 
- **A.2.6**: Core RAG foundation with basic node/relationship support
- **A.3**: Obsidian-style graph visualization + timeline view + character-centric timelines  
- **A.4**: Interactive knowledge map + plugin-specific visualizations + AI memory trace

### **Timeline System Module** ⏰
- **Features**: Visual, zoomable timelines for universes, stories, characters, items, and code entities
- **Integration**: Timeline selector integrated everywhere (editor, chat, RAG)
- **Advanced**: Dynamic relationship lines, overlay/split-view for comparison, plugin support for custom timeline events
- **UI Delivery**: Basic timeline visualization by A.3, interactive zooming and relationship lines by A.4

### **Reference & Encyclopedia Module** 📚
- **Features**: Character, item, and code entity sheets (traits, arcs, relationships, images, 3D params, docstrings, dependencies)
- **Advanced**: Visual network map for all entities, world encyclopedia with cross-linked places/lore/history, plugin-defined types
- **UI Delivery**: Basic entity sheets by A.3, network map and cross-linking by A.4

### **Character Bot Module** 🎭
**Persona-driven conversational AI integrated with timeline and RAG**

- **Features**: Select single/multiple characters for chat, timeline/context awareness for accurate responses
- **Advanced**: Mood/emotion tuning, step-in/out of character, out-of-universe/meta mode, insert dialogue/scenes into manuscript
- **UI Delivery**: Basic character selection and chat by A.3, timeline integration and mood controls by A.4

### **Plugin System Module** 🔌 **[RAG KNOWLEDGE CONTRIBUTOR]**
- **Features**: SDK for universe-specific rules, validation, UI/AI extension + **RAG knowledge seeding**
- **Advanced**: Plugin lifecycle API (load, activate, deactivate, unload, configure), plugins can register models/prompts/context/UI
- **Plugin Capabilities**: Define new RAG node types, timeline events, encyclopedia sections
- **RAG Seeding**: Plugins contribute coding examples, validation rules, AI templates, and universe-specific knowledge to RAG
- **Knowledge Types Seeded**:
  - **Validation Rules**: Universe physics, lore consistency, character behavior patterns
  - **Coding Examples**: Plugin development patterns, universe-specific calculations, AI templates
  - **AI Prompts**: Universe-appropriate response templates, character voice examples
  - **Timeline Schemas**: Universe-specific date systems, event categorizations
  - **Reference Data**: Species, technology, political systems, languages
- **Dynamic Knowledge**: Plugin activation seeds knowledge, deactivation removes it from active RAG
- **UI Delivery**: Plugin management interface by A.3, configuration and lifecycle controls by A.4, **knowledge seeding visualization by A.4**

### **Collaboration Module** 👥
- **Features**: Real-time multi-user editing (operational transform, WebSocket sync), inline comments, suggestion mode
- **Advanced**: Shared layouts and plugin state, role-based permissions and invitations, version control with rich history
- **UI Delivery**: Basic collaboration indicators by A.3, real-time editing and comments by A.4

### **Export & Integration Module** 📤
- **Features**: Export to ePub, PDF, DOCX, Markdown, custom publisher templates
- **Advanced**: Code export (repo zip, individual files, GitHub/Git integration), plugin system for external integrations
- **UI Delivery**: Basic export options by A.3, advanced formatting and plugin integrations by A.4

### **3D Model/Map System Module** 🌍 [FUTURE]
- **Features**: Parameterized 3D models and environments, timeline-driven morphing and overlays
- **Advanced**: Scene composition and export, plugin support for AI-driven 3D generation
- **UI Delivery**: Placeholder interface by A.4 (if time permits)

```typescript
interface AiChatMessage {
  type: "text" | "code" | "media" | "iframe" | "custom_ui";
```

### **🏗️ RAG Implementation Location & Service Architecture**

#### **RAG System Location: AI Server Integration**
- **IMPLEMENTATION**: RAG system will be integrated as a core service within the existing AI Server (port 8000)
- **SERVICE ENDPOINTS**: 
  - `/api/rag/nodes` - Node CRUD operations
  - `/api/rag/relationships` - Relationship management
  - `/api/rag/search` - Semantic search and retrieval
  - `/api/rag/context` - Context assembly for AI interactions
  - `/api/knowledge/graph` - Knowledge graph visualization data
  - `/api/knowledge/timeline` - Timeline-aware queries
- **INTEGRATION STRATEGY**:
  - Backend services call AI Server for all RAG operations
  - Plugin-seeded knowledge managed through AI Server plugin hooks
  - Encryption/decryption handled at AI Server level for RAG data
  - Close coupling with Ollama instances for efficient context assembly
- **RATIONALE**:
  - AI Server already orchestrates AI model interactions
  - RAG context assembly benefits from co-location with AI processing
  - Knowledge graph operations require tight integration with AI workflows
  - Maintains clean service boundaries while leveraging existing infrastructure
- **DATA FLOW**: Frontend ↔ Backend (auth/users) ↔ AI Server (RAG + AI models) ↔ MongoDB (persistence)
