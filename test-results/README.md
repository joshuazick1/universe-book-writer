# Test Results Directory

This directory contains timestamped test output files generated by the enhanced test runner with prettified console output.

## File Naming Convention

### Basic Test Files
- `test-results-YYYY-MM-DD-HHmm.txt` - Full test suite results
- `test-results-backend-YYYY-MM-DD-HHmm.txt` - Backend tests only
- `test-results-frontend-YYYY-MM-DD-HHmm.txt` - Frontend tests only
- `test-results-coverage-YYYY-MM-DD-HHmm.txt` - Tests with coverage report

### Enhanced Files with Issue Comments
- `test-results-backend-fixing-auth-bug-YYYY-MM-DD-HHmm.txt` - Backend tests with issue tracking
- `test-results-frontend-testing-new-feature-YYYY-MM-DD-HHmm.txt` - Frontend tests with comments
- `test-results-coverage-performance-testing-YYYY-MM-DD-HHmm.txt` - Coverage with issue context

## Enhanced Test Runner Features

### Dual Output Mode
- **Console**: Prettified output with ✅ checkmarks, ❌ for failures, ⏭️ for skipped tests
- **File**: Complete Jest output with headers, stack traces, and metadata

### Issue Tracking
Add comments to track what you're testing:
```bash
node scripts/run-tests-with-output.js --comment "Fixing auth bug" backend
node scripts/run-tests-with-output.js -c "Testing new feature" frontend
```

### File Headers
Each test result file includes:
- Execution timestamp and metadata
- Test type and command used
- Issue/comment for tracking
- Complete Jest output for debugging

## Test Commands

### NPM Scripts
- `npm test` - Run full test suite with enhanced output
- `npm run test:backend` - Run backend tests with output redirection
- `npm run test:frontend` - Run frontend tests with output redirection
- `npm run test:coverage` - Run tests with coverage and output redirection
- `npm run test:watch` - Run tests in watch mode (console only, no file output)

### Direct Script Usage
```bash
# Basic usage
node scripts/run-tests-with-output.js [test-type]

# With issue tracking
node scripts/run-tests-with-output.js --comment "Issue description" [test-type]

# Examples
node scripts/run-tests-with-output.js backend
node scripts/run-tests-with-output.js --comment "Fixing auth bug" backend
node scripts/run-tests-with-output.js -c "Testing new feature" frontend
```

## Cleanup

Old test result files should be cleaned up periodically to save disk space. Consider keeping only the most recent results or important milestone test runs.

## Git Ignore

Test result files (`*.txt`) in this directory are automatically ignored by Git to prevent cluttering the repository with test output logs. Only the README.md file is tracked.
