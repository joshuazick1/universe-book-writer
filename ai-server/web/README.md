# AI Server Web UI (Development Only)

This directory contains a minimal React + Vite + TypeScript frontend for interacting with the AI server during development.

- **Not for production use.**
- Do not run by default in production environments.

## Features
- View server status
- List available models
- Enter a prompt and get a (mocked) response
- Set basic configuration

## Setup

1. Install dependencies:
   ```powershell
   cd ai-server/web
   npm install
   ```
2. Start the dev server:
   ```powershell
   npm run dev
   ```
